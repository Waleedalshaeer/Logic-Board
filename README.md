Logic-Board

Logic-Board is an offline digital logic circuit simulator for Android.

Main Features

- Realistic virtual breadboard.
- Drag and drop digital components.
- Connect components using jumper wires.
- Simulate digital logic (0 and 1).
- Support logic gates and digital ICs.
- Save and load circuits locally.
- Fully functional offline.

Platform

Android APK

Project Status

Version 0.1 - Initial Development

Goal

Build a practical digital logic simulator for students to design, connect, and test digital circuits.# Logic-Board
